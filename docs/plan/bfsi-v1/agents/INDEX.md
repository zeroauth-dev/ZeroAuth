## 5-field DoD format (every daily ticket)

```
**W<n> <Day> <YYYY-MM-DD>** — <ticket subject>
- Done when: <objective, testable criterion>
- Output: `<file path | PR ref | email | document name>`
- Verify: <how a reviewer confirms — test command, file existence check, link check>
- Reviewer: Agent #<role number from 03-team.md>
- Depends on: <prior daily ticket id or commit id or "none">
```

## Conventions

- **Daily ticket ID** = `A<NN>-W<n>-<Day>` (e.g. `A06-W1-Mon` = Agent 6, Week 1, Monday).
- Days where an agent is in deep individual work (no PR, no meeting, no review) are explicitly listed as **focus blocks** so they are not mistaken for missing tickets.
- Friday afternoon every agent posts the 4-line status update per `06-ways-of-working.md`.
- Mon–Fri standup attendance is implicit; not listed as a daily ticket.
